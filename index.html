C. AKTIVITAS 1: EKSPERIMEN 10 + 20

Prediksi hasil sebelum menjalankan kode. Jalankan kode dan amati. Simpan file sebagai lkpd_string_number_nama.js.

let a = "10";
let b = "20";
console.log(a + b);
Pertanyaan Jawaban Kamu (Kunci Jawaban)
Apa output program? 1020
Mengapa hasil tersebut terjadi? Karena variabel a dan b bertipe String (teks), sehingga operator + melakukan penggabungan teks (konkatenasi), bukan penjumlahan matematika.
Apakah a dan b bertipe Number? Tidak, keduanya bertipe String karena nilainya diapit oleh tanda petik (" ").
Uji sekarang. Apakah prediksimu benar? Jelaskan. Ya, prediksi benar. Hasil console.log menunjukkan "1020" karena JavaScript menggabungkan kedua string tersebut.

D. AKTIVITAS 2: MENEMUKAN TIPE DATA

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama string string Nilai berupa teks yang diapit tanda petik.
umur number number Nilai berupa angka tanpa tanda petik.
Temuan: String digunakan untuk menyimpan teks (diapit tanda petik) dan tidak bisa dihitung secara matematis, sedangkan Number digunakan untuk menyimpan nilai angka yang dapat dihitung (operasi matematika).

H. THINK PAIR SHARE

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena fungsi prompt() selalu mengembalikan data bernilai String. Jika tidak dikonversi, operasi penambahan (+) akan menggabungkan teks, bukan menjumlahkan angka.
Apa perbedaan "10" dengan 10? "10" adalah String (teks), sedangkan 10 adalah Number (nilai numerik/angka).
Apa yang terjadi jika lupa Number()? Hasil perhitungan penambahan akan menghasilkan gabungan teks (misal "10" + "20" = "1020").

Pair: Hasil jawaban sama dengan teman sekelompok karena logika konversi tipe data JavaScript bersifat pasti.

Share: Penting untuk selalu memeriksa tipe data input sebelum melakukan perhitungan aritmatika di JavaScript.
